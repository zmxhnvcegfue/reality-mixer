## 🕹️ Overview

Reality Mixer composites a real-world camera feed with VR gameplay to produce mixed reality recordings, compatible with SteamVR and major headsets.

Whether you're a newcomer or a veteran, Reality Mixer provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **iPhone Tracking** | Uses iPhone camera with ARKit for accurate MR calibration |
| **Webcam Support** | Works with standard USB webcams for simple MR capture |
| **Green Screen** | Optional chroma key support for clean background removal |
| **OBS Compatible** | Output to OBS as a virtual camera source for streaming |
